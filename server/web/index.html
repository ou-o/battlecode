SEC.01

这是什么

BattleCode 骑码打仗 是一款把实体标签 + 摄像头识别 + 真人对战结合起来的类 MOBA 游戏。 玩家通过微信小程序加入游戏，用摄像头识别印有 AprilTag 25h9 的实体标签， 用拍摄代替攻击，推进战线，直至摧毁敌人的基地。

需打印：AprilTag 25h9 实体标签，贴在硬质板材上，固定佩戴于玩家头部或胸部。

SEC.02

玩法流程

  1. 建房 — 房主创建对局。玩家在微信小程序输入房间号加入。
  2. 选角 — 玩家选择阵营与角色，并录入自己佩戴的标签 ID（0–22）。
  3. 布防 — 房主录入掩体标签 ID（23–32），然后点击「开始游戏」。
  4. 开战 — 瞄得要准、跟拍要稳，战术配合、思路打开。
  5. 推进 — 掩体被摧毁后需撤下。玩家被击杀后需返回基地等待复活。
  6. 胜负 — 率先摧毁对手基地的一方获得胜利。
